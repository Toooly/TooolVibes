# Italian and English

`LocaleProvider` detects the first supported language in `navigator.languages`. Unsupported languages fall back to English. The shared header selector offers Italiano, English and automatic device language. An explicit selection is saved in `tooolvibes.language`, survives document navigation, and takes precedence over the device.

Italian remains the authored source and static HTML language. English is a static asset at `public/locales/en.json`, loaded once per document when needed. Public routes, authentication, tool identifiers and persisted workspace data remain unchanged. This keeps public prerendering and Cloudflare Free intact. English document language, titles and descriptions update in the browser; separate English SEO routes are not generated.

## Editing text

- Wrap display text in `LocalizedText`; it produces no additional DOM elements.
- Use `LocalizedAttributes` for accessibility labels, placeholders and titles. It forwards injected handlers, styles and refs to preserve interactive triggers.
- Use `useLocale().t` before truncating authored text, and translate individual list items before joining them. `LocalizedText` also supports a `separator` for an array of strings.
- Keep product names, URLs, code, IDs, input values, personal notes and other user content unchanged.
- Tool Markdown and guides translate prose before parsing. Links, code and callout markers are preserved; guide anchors derive from the original headings.

Add the corresponding English value to the dictionary when publishing new authored copy. Keys use the original text with whitespace collapsed. Template placeholders such as `{0}` must remain intact. Unknown content safely retains its original text; visitors do not use online machine translation.

After editing the dictionary, run `node scripts/i18n/refresh-version.mjs` before committing. The content fingerprint prevents stale browser caches. Validate with `npm run test:unit -- tests/i18n`, typecheck, lint and the Cloudflare build. Browser QA should cover automatic language, manual overrides across document navigation, mobile text wrapping and failed dictionary delivery.
