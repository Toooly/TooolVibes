# Competitor synthesis

Extract principles. Do not copy UI.

| Product | Pattern | Why it works | TooolVibes relevance | Decision |
|---|---|---|---|---|
| Product Hunt | Upvotes are not a library; people invent lists/notes to remember *why* | Discovery ≠ memory | Saved tools die without reason/context | ADAPT: every save can carry a light reason; journal captures why |
| StackShare | A stack is a named set of tools for a job | Identity + comparison at set level, not only 1:1 | Users already think in jobs (AI coding, client, free) | ADAPT: private named Stacks, not public company stacks |
| AlternativeTo | "People also use / alternative to X" | Decision is always relative | Compare already exists (2–5) | ADAPT: alternatives snapshot on decide; REJECT public opinion leaderboard |
| Raindrop | Unsorted inbox + collections + reminders | Prevents bookmark cemetery | Flat saved list is a cemetery | ADAPT: pipeline + resurfacing; REJECT nested folder OS |
| Readwise Reader | Inbox / Later / Shortlist / Archive + Daily Digest | Movement + gentle resurfacing | Stages saved/review/top already exist | ADAPT: map stages to Salvato → Da valutare → Candidato → Deciso |
| mymind | Save first, organize later; private; no social | Low friction, high return | Account must not feel like filing | ADAPT: Riprendi first; REJECT mandatory tagging |
| Pinterest | Boards as intent containers; secret boards | Named intent beats tags | Stacks = private boards of tools | ADAPT private boards; REJECT social feed |
| Notion Home | Recents + continue where you left off | Continuity > profile | Current hero leads with email | IMPLEMENT: Riprendi as first surface |
| Todoist Karma | Points + streaks + **opt-out / vacation / weekly goals** | Motivation without (if opted) daily shame | TV must not require daily use | ADAPT quiet mode + Active Weeks; REJECT daily streak loss |
| Duolingo | Quests, badges, **personal records**, leagues | Records motivate; leagues punish | Personal records OK | ADAPT records + marks; REJECT leagues/global leaderboard |

Filter: if it does not help someone make a better software decision, discard it.

Rejected: public leaderboards, daily compulsion, infinite moodboard without pipeline, generic SaaS stat-card home, black-box AI recs, Lucide-in-circle achievements.
