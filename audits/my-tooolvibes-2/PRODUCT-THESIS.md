# Product thesis

MY TOOOLVIBES IS NOT AN ACCOUNT DASHBOARD.

It is a personal software decision workspace.

## Loop

DISCOVER → SAVE → ORGANIZE → COMPARE → DECIDE → REMEMBER → RE-EVALUATE

Signal Progress reinforces the loop. It does not sit above it.

## What the first screen must answer

1. What was I doing?
2. What should I continue?
3. What have I saved that is stuck?
4. What am I comparing?
5. What have I already decided, and why?
6. What deserves attention now?
7. How is my personal map evolving?

## What it must never feel like

- profile page
- SaaS account dashboard
- bookmark list
- game panel
- settings page

## Strategic decisions (locked)

- One currency: Signal Points. Legacy XP never appears on this surface.
- One level grammar: Esploratore → Cartografo.
- Points only from server-verified meaningful behavior.
- No daily streak pressure. Optional Active Weeks (meaningful actions in a week).
- No global leaderboard.
- Quiet mode already exists — promote it to Settings.
- Persistence certified today must not regress (saved, compare, Decision Memory, guest merge).
- Existing `stack` list is a single working stack in discovery. Named Stacks are a new `personalStacks` collection.

## Surprise concept (one)

**Traccia della decisione** — when the user records an outcome, snapshot the current compare set (and keep any existing note/reason). Later the journal can answer "what was I comparing?" without a form.

Feasible, native, not creep. Strengthens the differentiator.

No second surprise.
