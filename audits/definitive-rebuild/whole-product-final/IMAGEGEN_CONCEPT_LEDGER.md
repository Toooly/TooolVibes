# ImageGen concept ledger

Ten route/system concepts were generated with the built-in ImageGen tool before
implementation. They were used as art-direction references, then reconciled
against the real repository contracts.

## Shared prompt system

Each prompt requested one coherent 1536×1024 product-system concept with:

- Command Center near-black and Decision Desk warm-ivory layers;
- Anton display, Fraunces editorial and Inter UI hierarchy;
- ultraviolet action, cyan factual/live and gold recognition accents;
- WAVE, SIGNAL, TRACE, ORBIT, NODE, PULSE, SCAN and LOCK primitives;
- restrained motion implications, dense but legible desktop/mobile structure;
- honest state language and no dependency on fabricated product records.

## Outputs and route focus

| Output | Prompt focus |
| --- | --- |
| `concepts/home-system.png` | decision-first discovery, Radar preview, weekly winner |
| `concepts/archive-system.png` | searchable editorial catalog and filter hierarchy |
| `concepts/tool-detail-system.png` | identity, verdict, canonical score and evidence |
| `concepts/radar-system.png` | live signal instrument plus factual unavailable state |
| `concepts/compare-system.png` | one-to-five candidate decision workspace |
| `concepts/saved-system.png` | persistent saved library, empty and populated states |
| `concepts/collections-index-system.png` | curated paths and special issue |
| `concepts/collection-detail-system.png` | rationale, ordered slots and next action |
| `concepts/account-system.png` | private decision-memory access context |
| `concepts/system-states.png` | search, loading, empty, error, locked and success grammar |

No generated image is shipped in the runtime UI. No generated copy, tool,
metric, score or feature was treated as product truth.
