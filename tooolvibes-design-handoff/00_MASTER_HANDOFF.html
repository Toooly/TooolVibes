Pages Mobile (375px)

🏠 Home — P0

Stack verticale. Titolo display ridotto (max 36px). CTA button lg full-width. Search bar sotto CTA. Sezioni: Hero → Catalogo (1 col) → Radar → Editorial → Footer.

🔍 Tool Discovery — P0

Filtri rapidi: scroll orizzontale chip/pill. Button "Filtri" → BottomSheet. Grid 1 colonna, card full-width. Card verticale: logo sopra, info sotto.

📋 Tool Detail — P0 (Hero #1)

Colonna singola. Header: logo + titolo h2/h3 + meta. CTA sticky bottom (salva + confronta). Tabs scroll orizzontale. Contenuto: stack verticale. "Tool simili": horizontal scroll card compact. Safe-area bottom 34px.

⚔️ Compare — P1

Header + toggle tabs. Tabella righe impilate verticalmente. Max 3 tool. Swipe/tab per cambiare tool visibile.

💾 Shortlist — P1

Header + contatore. Lista card verticali full-width. Swipe-left rimuovi. Stato vuoto: illustrazione + CTA discovery.

📝 Editorial — P1

Colonna singola centrata. Header: titolo h1, byline avatar + data. Immagine hero full-width. Body: testo, immagini, quote. Fine: tag, share, articoli correlati.

🎯 Service — P1

Hero centrato: titolo display + CTA primario + secondario. Blocchi feature 2-col alternati. Trust logos row. Pricing 2-3 card. CTA finale banner full-width.

Pages Desktop (1280px)

🏠 Home — P0

Hero 2-col (testo sx, illustrazione dx). Container max-width 1280px. Catalogo: grid 3-4 colonne. Radar: cerchi concentrici + leggenda. Editorial: 2-3 card affiancate. Space/12 tra sezioni.

🔍 Discovery — P0

2-col: sidebar filtri 280px sx (sticky top 80px), griglia 3 colonne dx. Gap 24px. Header: breadcrumb + titolo + contatore + ordinamento.

📋 Tool Detail — P0 (Hero #1)

2-col: contenuto ~70% sx, sidebar ~30% dx. Header: logo grande + h1/display + badge + meta. CTA row prominente. Tabs full-width underline. Sidebar: info box, "Tool simili" 2-3 card. Line-length max 75ch.

⚔️ Compare — P1

Tabella: colonne uguali + colonna fissa sx feature names. Cella: testo/badge/icona check-cross. Header colonna: logo + nome + rimuovi. Highlight winner = bordo accent. Max 4 colonne.

💾 Shortlist — P1

Header + contatore + azioni bulk. Grid 3-4 colonne, gap 24px. Card stato selected visibile. Sidebar opzionale suggerimenti. Stato vuoto centrato.

📝 Editorial — P1

Colonna singola centrata, max-width 720px testo. Immagine hero full-bleed o 1280px. Sidebar opzionale destra: indice sticky, articoli correlati. Fine: griglia 3 colonne articoli correlati.

🎯 Service — P1

Hero centrato/2-col. Blocchi feature 2-col alternati. Trust row. Pricing 2-3 card. CTA finale banner. Disclosure affiliate obbligatoria.
