# TooolVibes — Desktop Layouts (1280px)

## Viewport
- **Small desktop:** 1024px (laptop)
- **Standard:** 1280px (target principale)
- **Large:** 1440px
- **Wide:** 1920px (sanity check)

## Header / Nav — P0
- Logo sinistra, link nav centrati (o sinistra dopo logo), search centrale-destra, auth destra
- Container max-width 1280px centrato, padding orizzontale 24-48px
- Scrolled: sottile ombra, sfondo opaco, altezza ridotta
- Dropdown auth: sotto avatar, larghezza 200px, radius/lg

## Home — P0
- Hero: 2 colonne (testo sinistra, illustrazione destra)
- Titolo display, max 2 righe
- CTA: button lg + secondary affiancato
- Catalogo: grid 3-4 colonne card, gap 24px
- Radar: struttura visiva (cerchi concentrici), leggenda a lato
- Editorial: 2-3 card affiancate
- Space/12 (48px) tra sezioni
