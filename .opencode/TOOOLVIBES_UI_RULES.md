# TOOOLVIBES UI RULES (permanent)

1. Golden Master PNGs in `.opencode/golden-masters/` are the final UI specification.
2. Never claim visual parity without seeing pixels (image input, not OCR/DOM/scores).
3. Never use OCR, coordinates, tokens, or test results as visual approval.
4. Never preserve incorrect DOM anatomy just to minimize changes.
5. Never stack endless CSS override sheets (no parity-vN layers).
6. Preserve routing, data, auth, persistence, business logic.
7. Mobile Golden Master viewport = 390x844.
8. Always check tablet/desktop after mobile changes.
9. All final evidence must come from one SHA (CODE = BUILD = RUNTIME = SCREENSHOT).
10. Never deploy without explicit user authorization.
11. Never invent providers, URLs, product data, or assets.
12. Missing official imagery = ASSET BLOCKER. Document, do not fabricate.
13. Dynamic data may vary; visual component structure must not drift.
14. Tests passing is not visual approval.
15. If image vision is unavailable, STOP. Do not reconstruct from text.
